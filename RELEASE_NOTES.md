# Release Checklist

Short checklist used to rehearse the release-manager change lifecycle.

- [ ] Confirm thedefault branch is up to date and CI is green.
- [ ] Cut a feature/release branch (e.g. `drill/notes`) from `main`.
- [ ] Land the change as a pull request with a clear description and reviewers.
- [ ] Review the diff, leave comments, and request Copilot review if available.
- [ ] Merge the pull request and verify the commit SHA on `main`.
